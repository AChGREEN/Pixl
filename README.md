# Pixl

A retro‑styled personal website built with HTML and CSS, inspired by classic pixel‑RPG UI design.
This project serves as a simple, static showcase of who I am, what I’m building, and the things I enjoy!


**I built it to:**
-Revise my HTML/CSS fundamentals
-Experiment with pixel fonts, retro UI, and theming
-Learn how to structure clean, readable code
-Create a personal profile page that feels unique and fun

**Tech Stack**
HTML5
CSS3
Google Fonts (Press Start 2P, VT323)
VS Code
